# 基础块复查说明

本次以 comment.zip 的 25 张标注截图、用户补充的三层渲染截图和固定版本 Open Intelligent UI 源码为依据。新分享链接通过现有读取工具只返回空壳页面，未声称完整读取其正文。

## 只保留一个检查样例

首页、原聊天入口与原展厅入口全部显示同一份基础检查样例。旧的对话列表、45 个展厅案例、函数实验室和导入模拟对话不再作为页面入口。原有库源码与测试仍保留，未删除用户浏览器中的真实对话数据。

默认并排显示白色和黑色主题。整合版使用 Markdown 渲染与 OpenUI 交互组件；原版直接使用上游组件，并使用同一份内容数据。可切换原版、整合版、渲染器对比，亦可单独检查一种主题。
